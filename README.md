# Квест-бот для Telegram

## Структура репозитория

```
├── bot.py            — основной код бота
├── requirements.txt  — зависимости Python
├── Dockerfile        — образ для Railway
├── railway.toml      — конфигурация Railway
├── first.png         — картинка шаг 3  (добавьте сами)
├── second.png        — картинка шаг 4  (добавьте сами)
└── third.png         — картинка шаг 5  (добавьте сами)
```

## Деплой на Railway через GitHub

### 1. Подготовьте репозиторий

Загрузите в репозиторий `egorkalihanov2-create/kvest`:
- все файлы из этой папки
- изображения `first.png`, `second.png`, `third.png` в **корень** репозитория

### 2. Получите токен бота

Создайте бота через [@BotFather](https://t.me/BotFather) → `/newbot` → скопируйте токен.

### 3. Деплой на Railway

1. Зайдите на [railway.app](https://railway.app) → **New Project**
2. Выберите **Deploy from GitHub repo**
3. Выберите репозиторий `kvest`
4. В разделе **Variables** добавьте переменную:
   ```
   BOT_TOKEN=ваш_токен_от_BotFather
   ```
5. Railway сам соберёт Docker-образ и запустит бота.

### 4. Проверка

Перейдите к боту по ссылке от BotFather и отправьте `/start`.
